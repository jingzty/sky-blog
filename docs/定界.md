# 阶段 0 · 定界

## 一句话范围

**个人博客「远远的天空」——基于天空主题（黎明→正午→黄昏→星夜）一页式首页 UI，构建包含文章管理、分类管理、轮播图管理、站点配置的完整博客系统，支持草稿功能。**

## 页面与导航闭环

### 前台（5 页）

```
index.html（首页·天空漫游）
  ├─ #dawn → 黎明区（天空轮播 + 时刻轮播）
  ├─ #day  → 正午区（云朵文章卡片）
  ├─ #dusk → 黄昏区（分类地层 + 时间河）
  ├─ #night→ 星夜区（签名 + 搜索 + 登录入口）
  │
  ├─→ post.html?id=xxx（文章详情）
  ├─→ posts.html（文章列表，支持 ?category= / ?tag= / ?q= / ?month=）
  └─→ login.html（登录）

login.html ──→ admin/index.html（登录成功）
```

### 后台（6 页）

```
admin/index.html（仪表盘）
  ├─→ admin/posts.html（文章列表）
  │     └─→ admin/editor.html（新建/编辑文章）
  ├─→ admin/categories.html（分类管理）
  ├─→ admin/slides.html（轮播图管理）
  └─→ admin/config.html（站点配置）
```

### 导航闭环检查

- 前台任意页面可回到首页
- 文章详情可回到首页 / 列表
- 登录成功进后台，登出回登录页
- 后台各页面互相切换（导航栏）
- 404 页有兜底返回链接
- 无死胡同
