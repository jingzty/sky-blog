## 契约 B · 字段表

### B1. 文章（posts）

| 字段名 | 类型 | 说明 | 可空 |
|---|---|---|---|
| id | INTEGER | 自增主键 | — |
| title | TEXT | 标题 | ❌ |
| slug | TEXT | URL 友好标识（唯一） | ❌ |
| excerpt | TEXT | 摘要/导语 | ✅ |
| cover | TEXT | 封面图 URL | ✅ |
| date | TEXT | 发布日期 YYYY-MM-DD | ❌ |
| tag | TEXT | 标签（逗号分隔） | ✅ |
| content | TEXT | Markdown 正文 | ❌ |
| status | TEXT | draft / pub | ❌ |
| categoryId | INTEGER | 所属分类 ID | ✅ |
| createdAt | TEXT | 创建时间 ISO | ❌ |
| updatedAt | TEXT | 更新时间 ISO | ❌ |

### B2. 分类（categories）

| 字段名 | 类型 | 说明 | 可空 |
|---|---|---|---|
| id | INTEGER | 自增主键 | — |
| name | TEXT | 分类名（唯一） | ❌ |
| description | TEXT | 分类描述 | ✅ |
| color | TEXT | 地层颜色 CSS 类名(s1-s7) | ❌ |
| sortOrder | INTEGER | 排序 | ❌ |

### B3. 轮播（slides）

| 字段名 | 类型 | 说明 | 可空 |
|---|---|---|---|
| id | INTEGER | 自增主键 | — |
| postId | INTEGER | 关联文章 ID | ❌ |
| tag | TEXT | 轮播标签文字（如"旅行手记 · 黎明"） | ❌ |
| title | TEXT | 轮播标题 | ❌ |
| description | TEXT | 轮播描述 | ❌ |
| bgImage | TEXT | 天空背景图 URL | ❌ |
| sortOrder | INTEGER | 排序 | ❌ |
| status | TEXT | active / inactive | ❌ |

### B4. 站点配置（siteConfig）

| key | 说明 | 默认值 |
|---|---|---|
| blogName | 博客名 | 远远的天空 |

| authorBio | 作者简介 | 热爱天空的人…… |
| authorAvatar | 头像 URL | images/avatar.jpg |
| githubUrl | GitHub | — |
| weiboUrl | 微博 | — |
| contactEmail | 联系邮箱 | — |
| footerText | 页脚文案 | © 2026 远远的天空 |

### B5. 用户（users）

## 契约 C · API 表

### C1. 认证

| 业务动作 | 方法 | 路径 | 鉴权 | 请求体 | 响应 |
|---|---|---|---|---|---|
| 登录 | POST | /api/login | — | {username, password} | {token} |
| 验证令牌 | GET | /api/check | ✅ | — | {valid: true} |

### C2. 文章

| 业务动作 | 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|---|
| 前台列表 | GET | /api/posts | — | ?status=pub，支持 ?categoryId=&tag=&q=&month=&page=&limit= |
| 后台列表 | GET | /api/posts?all=1 | ✅ | 含草稿 |
| 详情 | GET | /api/posts/:idOrSlug | — | 公开 |
| 新建 | POST | /api/posts | ✅ | |
| 更新 | PUT | /api/posts/:id | ✅ | |
| 改状态 | PATCH | /api/posts/:id/status | ✅ | {status: "draft"|"pub"} |
| 删除 | DELETE | /api/posts/:id | ✅ | |

### C3. 分类

| 业务动作 | 方法 | 路径 | 鉴权 |
|---|---|---|---|
| 列表 | GET | /api/categories | — |
| 新建 | POST | /api/categories | ✅ |
| 更新 | PUT | /api/categories/:id | ✅ |
| 删除 | DELETE | /api/categories/:id | ✅ |

### C4. 轮播
